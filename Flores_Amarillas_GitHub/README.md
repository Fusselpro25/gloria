# 🌻 Flores Amarillas para Gloria Domínguez Muñoz

Una página web romántica e interactiva creada especialmente para **Gloria Domínguez Muñoz** de parte de **Joel Gómez García**, inspirada en la tradición del 21 de septiembre y la canción de *Floricienta*.

---

## ✨ Características
- **Sobre postal vintage interactivo** con sello de *Los Girasoles* de Vincent van Gogh.
- **Música de Floricienta ("Flores Amarillas")** que inicia automáticamente en el coro: *"Ella sabía que él sabía que algún día pasaría..."*
- **Dedicatoria estilo créditos de película**: Ascenso suave del texto con tipografía clásica y el recuerdo especial de los 2 años desde que se empezaron a seguir en Instagram.
- **Ramo animado de flores amarillas** floreciendo con efecto botánico.
- **Lluvia suave e interactiva de pétalos amarillos** y motas de luz doradas al mover el ratón o deslizar en el móvil.

---

## 🚀 Cómo publicarlo gratis en GitHub Pages (para enviarle el enlace a Gloria)

Para que Gloria pueda abrir la web directamente desde su teléfono (por WhatsApp o Instagram) con un link propio, sigue estos sencillos pasos:

1. **Crear repositorio en GitHub**:
   - Entra en [github.com/new](https://github.com/new).
   - En **Repository name**, escribe por ejemplo: `flores-amarillas` (o el nombre que prefieras).
   - Asegúrate de marcarlo como **Public**.
   - Haz clic en **Create repository**.

2. **Subir los archivos**:
   - Puedes arrastrar y soltar todos los archivos y carpetas de esta misma carpeta (`index.html`, `style.css`, `script.js`, carpeta `assets`) directamente a la página de GitHub.
   - O usando la terminal de Git:
     ```bash
     git init
     git add .
     git commit -m "Flores amarillas para Gloria"
     git branch -M main
     git remote add origin https://github.com/TU_USUARIO/flores-amarillas.git
     git push -u origin main
     ```

3. **Activar GitHub Pages**:
   - En tu repositorio de GitHub, ve a la pestaña **Settings** (Configuración).
   - En el menú izquierdo, haz clic en **Pages**.
   - En **Branch**, selecciona `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**.

4. **¡Listo!**:
   - En 1 o 2 minutos, GitHub te dará un enlace público como:
     `https://TU_USUARIO.github.io/flores-amarillas/`
   - ¡Copia ese link y envíaselo a Gloria! 💛
